# Medijski Atlas

Pregled slovenskega medijskega prostora — izobraževalno orodje za medijsko pismenost.

- 📊 **Politična orientacija**: analiza usmeritve in dinamike poročanja
- 🔍 **Zanesljivost dejstev**: ocene metodologije, preverjanja virov in novinarskih standardov
- 🏛️ **Lastniška struktura**: transparenten vpogled v lastništvo in vplive slovenskih medijev
- 📰 **Katalog medijev**: spletni portali, tisk, televizija in radio
